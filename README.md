## 🧭 About Me

I’m **Gokul Das** — an AI &amp; ML undergrad pursuing a **B.E. in Artificial Intelligence &amp; Machine Learning** at **Chennai Institute of Technology** (CGPA 8.76) alongside a **B.S. in Data Science** at **IIT Madras** (CGPA 8.13). I build **agentic AI systems**, LLM-powered applications, and data-driven products — the kind that translate messy natural-language intent into real, verifiable action.

- 🧠 **Deep on RAG &amp; retrieval** — hybrid retrieval (BM25 + semantic search), hierarchical chunking, citation-backed generation, and privacy-preserving offline assistants.

- 🌱 **Currently going deeper on** on-device LLM optimization, agent observability, and latency-aware inference pipelines.

## 🚀 Featured Projects

### 🗃️ [AI Database Analyst (AIDB)](https://github.com/ggokuldas06) — Natural language → SQL → insight
An **agentic AI platform** that turns plain-English business requests into SQL queries and analytical reports — with query validation and self-correction built in.

- **Highlights:** processes requests in **under 4 seconds** average response time across databases with **100K+ records**.
- **Architecture:** custom **MCP server** for dynamic schema discovery + PostgreSQL execution (no predefined schemas needed) → **LangGraph** multi-agent workflow with validation, self-correction, and guardrails against prompt injection and unsafe SQL.
- **Stack:** `Python` · `FastAPI` · `LangGraph` · `MCP` · `PostgreSQL` · `Vue.js`

### 💻 [AICode CLI](https://github.com/ggokuldas06) — AI coding assistant from natural language
Generates, executes, tests, and debugs full software projects straight from natural-language requirements.

- **Pipeline:** multi-agent workflow for planning → code generation → execution → iterative debugging, with sandboxed execution and persistent project state.
- **Stack:** `Python` · `LangGraph` · `LangChain` · `OpenAI` · `Gemini` · `Typer`

### 🧓 [SeniorCare](https://github.com/ggokuldas06) — AI-assisted elder care platform
A voice-first elder-care system with a custom Android launcher and guardian monitoring.

- **Features:** hybrid NLP pipeline combining **TF-IDF + LLM inference** for **90%+ intent classification accuracy**, real-time communication, medication reminders, and alert routing via WebSockets with secure device pairing.
- **Stack:** `Kotlin` · `FastAPI` · `Scikit-Learn` · `React Native` · `Node.js`

### ⚖️ [LegalAI](https://github.com/ggokuldas06) — Offline privacy-preserving legal assistant
A fully **offline, multimodal Agentic RAG** legal assistant built during my AI Lab internship.

- **Architecture:** hierarchical chunking + hybrid retrieval (**BM25 + semantic search**) + multi-stage agentic document routing for cross-document reasoning, all running on local LLMs via **Ollama**.
- **Capabilities:** document summarization, clause extraction, and **IRAC-based** legal reasoning with citation-backed generation across PDFs, scanned documents, and images.
- **Stack:** `Django REST` · `Vue.js` · `Ollama` · `local LLMs` · `BM25`

> 🔬 **Also worth a look:** on-device vision LLM work (Qwen3-VL, Gemma 3n, PaliGemma) for automotive damage detection, and a voice-routing agent for truck drivers built with Google ADK + a custom MCP server.
